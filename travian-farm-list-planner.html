    Horse budget by radius

    An alternative to priority order: each radius prices all enabled, listed targets inside that circle. A partially scanned circle is only a lower bound. A funded distant target does not mean every nearer target fits.

    How the allocation works

    Each target is rounded up separately, then added to the running total. A horse still on its return trip cannot take the next departure. Only enabled targets add to the totals. These are ideal rotations without a reserve for losses, delayed returns or other missions.

    Coverage & source

    Calculations run locally. Cloudflare Web Analytics records page visits and performance statistics. No automatic game requests, farming timers, polling or troop sending. The selected six- or ten-minute interval is only used in the calculation. Map geometry: 401 × 401, wrapping at -200/+200. Occupied oases are excluded.
