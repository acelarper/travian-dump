Timing notes & GitHub Pages setup

Measured, not magic. Each browser independently makes five uncached HTTPS requests to TimeAPI.io's CORS-enabled /api/time/current/zone?timeZone=UTC endpoint. Its UTC timestamp has fractional seconds. No account, API key, backend, or direct NTP connection is used.

For each response, the server timestamp is compared with the midpoint of the request's performance.now() round trip. At least three usable samples are required. The median offset of the three fastest samples calibrates a monotonic clock reference. The uncertainty estimate includes their half-round-trip delays, offset spread, timestamp rounding, and an assumed 100 ppm of drift (6 ms per minute) between synchronizations.

This estimates network uncertainty, not certified millisecond accuracy. Network paths can be asymmetric; the service's own UTC error and your device's actual oscillator drift are unknown. Milliseconds describe display resolution. The clock updates at the screen's refresh rate. Synchronization repeats every five minutes while visible, retries after a minute on failure, and refreshes after returning to the page. Unavailable, expired, or interrupted calibration falls back to the computer clock and is clearly marked unsynchronized.

Dates and sound. The arrival date starts at today in the selected timezone. Both time fields accept single- or double-digit hours, such as 0:09:28, and optional .mmm. Travel also accepts copied text such as in 10:42:19 hrs., hours alone, or hours and minutes. Omitted travel minutes or seconds are zero: both 1 and 1:00 mean 01:00:00. Travel is elapsed time, including across midnight and daylight-saving changes. London uses the browser's IANA timezone data, including BST (UTC+1). Nonexistent spring times are rejected; repeated autumn times require an explicit choice. Sound is off on every page load. Enabling it unlocks browser audio and schedules 3, 2, 1, and send cues. The target cue briefly reads SEND NOW, then MISSED with elapsed time; neither confirms a game action. Keep the page visible, preferably beside Travian: background tabs, sleeping devices, muted browsers, and audio output latency can delay or prevent cues.

Publish this one file:

  1. Create a public GitHub repository and upload travian-clock.html to its root on the main branch.
  2. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, then main and / (root). Save.
  3. After GitHub finishes publishing, append travian-clock.html to your repository's Pages URL, for example https://username.github.io/repository/travian-clock.html, and share that address. No build command, npm installation, or server configuration is needed.

You can also open this file locally. Without an accessible time service it still calculates send times, but its clock is unsynchronized. No calculator inputs are uploaded or saved. Cloudflare Web Analytics records page visits and performance statistics.
