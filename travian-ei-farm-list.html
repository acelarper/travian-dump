Using the numbers

Start with row 1 and work downward. To run the first 10 targets at the stated cadence, allocate 68 EI. For any other stopping point, read that row's Cumulative EI.

Each oasis has its own rotation allocation. A horse that is still returning cannot be used for the next departure. The ceiling accounts for that; no automatic timer, queue or sending is implemented here.
